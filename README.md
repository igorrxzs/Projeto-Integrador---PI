# Museu do Inexistente

## Sobre o Projeto

O Museu do Inexistente é um projeto de arte digital interativa desenvolvido para a disciplina de P5.js e desenvolvimento web.

A proposta do projeto é criar uma experiência artística virtual inspirada em museus surreais, utilizando animações, interações e elementos visuais criados com programação.

O museu será dividido em diferentes salas temáticas, onde cada página representa uma experiência visual única, explorando conceitos como:

- tempo;
- vazio;
- sonhos;
- infinito;
- memórias;
- transcendência.

O projeto busca unir arte digital, criatividade e programação interativa através do uso da biblioteca P5.js.

---

## Objetivo

Criar uma exposição digital interativa composta por múltiplas páginas conectadas entre si, utilizando sketches desenvolvidos em P5.js integrados com HTML e CSS.

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- P5.js

---

## Estrutura do Projeto

O projeto será dividido em diferentes salas do museu:

- Entrada do Museu
- Sala do Tempo
- Sala do Vazio
- Sala do Infinito
- Sala dos Sonhos
- Sala das Memórias
- Sala Final

Cada sala possuirá:
- identidade visual própria;
- animações;
- interações com o usuário;
- elementos artísticos desenvolvidos com P5.js.

## Recursos do Projeto
