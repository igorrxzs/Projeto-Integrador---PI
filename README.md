# Elevador Infinito

## Sobre o Projeto

O Elevador Infinito é um projeto de arte digital interativa desenvolvido para a disciplina de P5.js e desenvolvimento web.

A proposta do projeto é criar uma experiência virtual dentro de um elevador misterioso, onde cada andar apresenta uma realidade diferente, estranha e imprevisível. O usuário poderá interagir com o elevador escolhendo entre subir, descer ou abrir a porta, e cada escolha irá modificar a experiência visual e narrativa do jogo.

O elevador levará o jogador para diferentes andares temáticos, como:

* andar dos memes;
* andar sem gravidade;
* andar todo vermelho;
* andar bugado;
* andar silencioso.

O projeto busca unir criatividade, humor, suspense e programação interativa através do uso da biblioteca P5.js.

## Objetivo

Criar uma experiência digital interativa em formato de jogo, onde o usuário explora um elevador infinito com diferentes andares, animações e eventos visuais criados com P5.js.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* P5.js

## Estrutura do Projeto

O projeto será dividido em diferentes estados ou telas do elevador:

* Tela inicial
* Interior do elevador
* Andar dos Memes
* Andar Sem Gravidade
* Andar Vermelho
* Andar Bugado
* Andar Silencioso
* Tela Final ou Continuação Infinita

Cada andar possuirá:

* identidade visual própria;
* animações diferentes;
* interações com o usuário;
* mudanças no ambiente conforme as escolhas;
* efeitos visuais desenvolvidos com P5.js.

## Recursos do Projeto

* Animações em canvas
* Interações com mouse
* Botões de subir, descer e abrir porta
* Mudança de cenário conforme o andar
* Efeitos visuais
* Experiência interativa e imersiva
* Elementos de humor, suspense e surpresa
